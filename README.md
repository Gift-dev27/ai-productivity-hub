# AI Productivity Hub

Build a modern, responsive SaaS-style web app called AI Workplace Productivity Assistant.

Core Requirements

Create a clean, professional dashboard using light purple, white, and soft grey with modern cards, subtle shadows, rounded corners, and excellent spacing. The app should work on desktop, tablet, and mobile.

Navigation

Add a left sidebar with:

Dashboard

Meeting Notes

Task Planner

AI Assistant

No registration, login, account creation, or backend. The app should function entirely as a frontend prototype with AI-generated content.

Dashboard

Create a welcoming productivity dashboard showing:

Today's productivity overview

Upcoming tasks

Recent meeting summaries

Priority tasks

Quick-action buttons for each AI feature

Meeting Notes Summarizer

Create an interface where users can paste or enter lengthy meeting notes.

AI should generate:

Concise meeting summary

Key discussion points

Decisions made

Action items

Deadlines

People responsible for tasks

Allow users to edit the generated AI output before copying or saving it.

Include example AI-generated meeting content so the interface looks populated.

AI Task Planner

Allow users to enter their tasks and optionally specify:

Priority

Deadline

Estimated duration

AI should generate a structured daily or weekly schedule, prioritising important tasks and organising them into realistic time blocks.

Display results as attractive task cards or a timeline. Make generated tasks editable.

AI Workplace Assistant

Create a modern chatbot interface where users can ask workplace/productivity questions.

Include example prompts such as:

"Plan my workday."

"Help me prioritise these tasks."

"Draft a professional follow-up."

"Summarize this project."

"How can I manage my workload?"

All responses should appear as AI-generated workplace assistance in a polished chat interface.

AI Prompt Design

Use structured, workplace-focused prompts behind each feature so responses are:

Professional

Concise

Action-oriented

Easy to understand

Relevant to workplace productivity

Responsible AI

Add a subtle disclaimer throughout the app:
"AI-generated content may contain errors. Review important information before relying on it."

UX Requirements

Modern SaaS dashboard aesthetic

Responsive layout

Clear typography and hierarchy

Light purple and grey colour palette

Smooth hover/focus states

Editable AI outputs

Copy buttons where useful

Empty states and example content

Clear loading states for AI generation

No authentication

No registration/sign-in pages

No backend or database

Frontend/prototype experience only

Populate the application with realistic AI-generated sample content so every screen feels complete and usable immediately.
